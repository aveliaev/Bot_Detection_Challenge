# Цикл 4: независимые детекторы по каналам и decision-level fusion — итоговый отчёт

**Итоговое решение: KEEP B0.** Поиск признаков не продолжаем. Финальное решение — B0 и `submission.csv` цикла 2 (скрытый test 0.8953).

Гипотеза цикла: отдельные детекторы для каналов mouse / behavior / item плюс слияние решений (идея Iliou et al., 2021) используют противоречие между каналами лучше единой модели и убирают упорные FP. Результат:

- **Противоречие между каналами у упорных FP действительно есть.** В парах с одинаковым score B0 у упорных FP высокий mouse и item, но низкий behavior; у TP наоборот.
- **Ни одно слияние (21 правило) не превзошло B0.** Лучшее — meta-LR: 0.892 на repeated CV (−0.008) и 0.886 на fwd7 (−0.017).
- Единственное правило, которое опускает часть упорных FP (7 из 45), одновременно добавляет 12 новых FP и теряет 16 TP.
- Stop condition выполнен.

## 0. Статья и её главная идея
Iliou, Kostoulas, Tsikrika, Katos, Vrochidis, Kompatsiaris. *Detection of Advanced Web Bots by Combining Web Logs with Mouse Behavioural Biometrics.* DTRAP 2(3), art. 24, 2021. DOI 10.1145/3447815.

**Ограничение.** Полный текст открыть не удалось: сетевая политика среды блокирует все хосты, где он лежит — dl.acm.org, eprints.bournemouth.ac.uk, zenodo.org, m4d.iti.gr, colab.ws, echonetwork.eu, api.semanticscholar.org. Метод восстановлен по проиндексированным поиском фрагментам статьи и диссертации автора (Bournemouth, 2022). Ключевые элементы подтверждены дословными цитатами:

1. **Два независимых модуля:**
   - по web-логам: признаки сессии, ансамбль SVM, Random Forest, AdaBoost и MLP с голосованием;
   - по траекториям мыши: CNN.
2. Каждый модуль выдаёт score в [0, 1]: чем больше, тем вероятнее бот.
3. **Слияние на уровне решений** использует то, что модули смотрят на сессию с разной детальностью:
   - mouse-модуль уверен (score ≥ thres_h = 0.7) — решает он;
   - mouse-модуль уверен в человеке (score ≤ thres_l = 0.3) — тоже решает он;
   - в промежутке берётся среднее двух модулей (w_mv = w_wl = 0.5), сессия считается ботом при среднем ≥ 0.5.
4. Порогов 0.7 / 0.3 и весов 0.5 / 0.5 авторы подбирали по валидации.

**Что перенесено:** главная идея — независимые детекторы на разделённых каналах плюс слияние на уровне решений. Реализованы оба варианта: правило статьи с её порогами дословно и пороги, подобранные только по OOF.

**Что не копировалось:** CNN по изображениям траекторий. В данных у каждого события одна точка курсора, траекторий нет, и в этом цикле новых признаков не строим.

## 8. Слияние по Iliou et al.
Web-модулем статьи у нас служит behavior или среднее behavior и item. Без курсора работает только web-модуль. Подобранные пороги кросс-фитились по фолдам (fwd7 — по вложенному OOF дней обучения).

| вариант | repeated CV | fwd7 |
|---|---|---|
| пороги статьи 0.7 / 0.3, web = behavior | 0.754 | 0.703 |
| пороги статьи 0.7 / 0.3, web = behavior + item | 0.872 | 0.871 |
| OOF-пороги, web = behavior | 0.765 | 0.703 |
| OOF-пороги, web = behavior + item | 0.873 | 0.868 |

Подобранные пороги почти всегда th = 0.5–0.7, tl = 0.05: «доверять mouse, когда он уверен» переносится. Но тот же механизм и поднимает упорные FP, у которых mouse ≈ 0.97.

## 14. Leakage audit (`research4/test_leakage4.py` — все **ok**)
- Слияние в repeated CV: score фолда k не меняется при переворачивании меток фолда k (wmean, Iliou-fit, meta-LR, meta-CatBoost).
- fwd7: score валидационных строк не меняется при переворачивании **всех** меток дней валидации. Параметры берутся из вложенного OOF по дням обучения; для k = 7 это дни 2–6.
- Каналы не пересекаются. Mouse видит только столбцы курсора; behavior не видит курсор, item и UA; item не видит курсор, UA и тайминги.
- Эксперты используют тот же конвейер, что B0: пул item пересчитывается в каждом фолде только по меткам обучения, тесты цикла 2 это покрывают. B0 воспроизведён бит-в-бит.
- Результатов ≥ 0.92 нет, так что расширенный аудит из пункта 15 не требуется.

## 15. FINAL DECISION: **KEEP B0**
Stop condition:
- **Прирост от слияния:** ни одно правило не даёт > +0.01. Все 21 ниже B0 и на repeated CV (лучшее −0.008), и на fwd7 (лучшее −0.017). P(лучше B0) по paired bootstrap ≤ 0.22.
- **AUC признаков противоречия:** формально максимум 0.764, но только в направлении «у FP выше mouse и item». Этот сигнал нельзя использовать монотонно, а немонотонные meta-модели, у которых он был на входе, проиграли B0. В полезном направлении лучший признак — 0.646, это меньше 0.70.

**Почему поздний фьюжн проигрывает единой модели.**
- Противоречие каналов у упорных FP реально: высокие mouse и item при низком behavior. Но такой же профиль у многих настоящих ботов: mouse-ботов с человеческим ритмом, которых ловят именно курсор и пул.
- B0 видит все каналы сразу и уже учитывает их взаимодействия на уровне признаков. Эксперты, разделённые по каналам, эти взаимодействия теряют, а слияние по score их не восстанавливает.
- Это согласуется с выводом цикла 3: упорные FP порождены теми же генераторами курсора и пула, что и боты, и отличаются только ритмом, который B0 уже использует.

**Итог.** Доступные данные исчерпаны. Финальное решение — **B0**. `submission.csv` не меняется: CatBoost на топ-120 признаках плюс пул item, среднее по 5 seed, скрытый test 0.8953, воспроизводится `python solution/train_final_v2.py`. Поиск признаков не продолжаем.
