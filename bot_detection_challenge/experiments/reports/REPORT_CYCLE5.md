## 1. Что проверялось
**Гипотеза:** B0 не меняем. Внутри узкой полосы рангов около рабочей точки меняем местами кандидатов, которых B0 уже считает похожими на ботов, используя противоречие каналов из цикла 4.

**Правила:**
- B0 заморожен. Новых признаков нет, новой глобальной модели нет.
- Входы — только уже посчитанные OOF-оценки: B0, mouse, behavior, item, context; плюс платформа, `mouse_available` и признаки противоречия:
  - mouse − item, behavior − item, mouse × item;
  - std, min, max по оценкам каналов.
- **Вне полосы** новая оценка равна B0.
- **Внутри полосы** новая оценка = ранг B0 + λ · поправка. Результат обрезается границами полосы, поэтому ничего снаружи не сдвигается, а кандидаты полосы могут меняться местами только друг с другом.

## 3. Методы внутри полосы
| метод | суть | параметры |
|---|---|---|
| **local_lr** (matched local training) | для кандидата с B0 = p логистическая регрессия на обучающих OOF-строках полосы с \|B0_train − p\| < δ; поправка = локальная апостериорная вероятность минус доля ботов в окне | δ ∈ {0.02, 0.05, 0.10}, λ ∈ {0.01, 0.02, 0.05, 0.1} |
| **pair** (pairwise local objective) | пары «TP против негатива» из обучающих фолдов с \|B0_TP − B0_neg\| < ε; линейная логистическая модель на X(TP) − X(neg) без свободного члена; поправка = tanh(w · x) | ε ∈ {0.02, 0.05, 0.10}, те же λ |
| **pair_sub** (по подтипам) | тот же pairwise, но отдельные модели для web + mouse, web без mouse и mobile; mouse-признаки только для web + mouse | ε, λ те же |
| **rule** (conditional rule цикла 4) | в полосе: mouse > tm, item > ti, behavior < tb → сдвиг вниз на r позиций | tm ∈ {0.90, 0.95}, ti ∈ {0.85, 0.90, 0.95}, tb ∈ {0.2, 0.3, 0.4}, r ∈ {5, 10, 20, 30} |

Всего 649 конфигураций, включая «ничего не делать».

## 4. Протокол: всё кросс-фитировано и вложено
- **Внешняя оценка** — точно те же строки и фолды, что у B0: P0–P4 (6 фолдов в каждой) и fwd7 (k = 5, 7).
- Для внешнего фолда k каждая конфигурация обучается только на OOF-строках *других* фолдов. Для fwd7 — только на вложенном OOF по дням обучения из цикла 4: дни 2–4 для k = 5 и дни 2–6 для k = 7.
- **Выбор конфигурации — только вложенный.** Внутри обучающей части делается внутренняя кросс-валидация: внутренние фолды — это остальные фолды разбивки, а для fwd7 — отдельные дни обучения. Выбирается конфигурация с лучшим внутренним P@R, причём только если она лучше «ничего не делать» на внутренних данных. Затем она один раз применяется к внешнему фолду.
- Внешние фолды используются только для итоговых чисел. Таблица фиксированных конфигураций (раздел 7) приведена для прозрачности и ни для какого выбора не использовалась.

## 6. Что выбирала внутренняя валидация
По 32 внешним фолдам: local_lr — 16 раз, pair — 12, pair_sub — 1, «ничего» — 3. Правило из цикла 4 не выбрано ни разу. Внутренний выигрыш у выбранных конфигураций составлял от +0.0004 до +0.024, а на внешних фолдах результат во всех пяти разбивках отрицательный.

Это типичный шум выбора: внутри полосы около 20–30 ботов на фолд, и любое переранжирование, выглядящее выигрышным на своих данных, на новых фолдах не повторяется. Полный список выборов — `research5/nested_choices.csv`.

## 9. Почему не сработало
- В полосе около рабочей точки упорные FP и TP с теми же оценками B0 различаются только сочетанием каналов (цикл 4: FP — mouse и item высокие, behavior низкий).
- Но точно такое же сочетание у значительной части настоящих ботов этой полосы. Любая поправка, которая опускает такие FP, двигает и TP, а на их место поднимаются другие негативы. В web + mouse это 4 убранных FP против 15 добавленных.
- Независимого сигнала, который различал бы их внутри полосы, в имеющихся оценках нет. Это согласуется с циклами 3 и 4.

## 10. Итог
**B0 IS FINAL.**
- Решение: CatBoost на топ-120 признаках плюс пул item, среднее по 5 seed.
- Оценки: repeated CV 0.9003, fwd7 0.9023, скрытый test 0.8953.
- Воспроизведение: `python solution/train_final_v2.py` даёт бит-в-бит тот же `submission.csv`.

Четыре больших исследовательских цикла и эксперимент с локальным переранжированием не нашли независимого сигнала сверх B0. Исследование закрыто.
