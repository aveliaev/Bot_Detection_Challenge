# Цикл 6.5: условные межканальные остатки — заключительный эксперимент на опровержение

# Вердикт: **NO USEFUL CROSS-MODAL SIGNAL — B0 IS FINAL**

Вопрос эксперимента: при одинаковой общей «ботскости» можно ли отличить настоящего бота от упорного FP по тому, насколько поведение одного канала неожиданно с учётом других каналов?

**Ответ: нет.**

1. **Mouse → behavior: связи нет.** Курсор объясняет около 1% вариации поведения (ΔR² +0.011 к одному контексту), перемешивание курсора почти не ухудшает прогноз. Ветка провалила gate качества отображения. Поверх item курсор не добавляет ничего (ΔR² +0.0001).
2. **Связи item ↔ behavior реальны** (ΔR² 0.21–0.29, перемешивание явно вредит), но их остатки не отделяют упорные FP. Лучшие признаки дают 0.54–0.61 после сопоставления по числу событий. «Хороший» результат 0.665 у MB_L1 — это смешение с длиной cookie.
3. **Остаток behavior → item** — самый сильный условный сигнал за все циклы: AUC 0.66 в полосе рабочей точки, стабилен по неделям. Но он направлен не туда: у упорных FP пула объявлений *больше*, чем ожидается по их поведению, так что он делает их ещё «ботее». И в модели он не даёт прироста: информация уже есть в признаках пула B0.
4. **Интеграция в B0 провалилась во всех ветках.** Лучший вариант: +0.001 на repeated CV при −0.012 на fwd7. Все 45 упорных FP остаются.

Свежий прогон цикла 6 (`research6/r0_reproduce_b0.py`): 0.9003 ± 0.0035, fwd7 0.9023. OOF-массивы всех шести схем **побитово равны** массивам цикла 2; проверено повторно в начале цикла 6.5.

## 6. Определения остатков (`research65/cross_modal.py`)
Остаток = стандартизованный факт − прогноз, по каждому измерению, знак сохраняется. Сводки: не больше 7 на отображение, всего 27.

| сводка | смысл |
|---|---|
| `X_L1`, `X_L2`, `X_max` | величина остатка |
| `X_timing` | + означает паузы длиннее ожидаемых |
| `X_dtmed` | факт − прогноз медианной паузы |
| `X_activity` | + означает активности больше ожидаемой |
| `X_eventmix` | модуль остатка по набору событий |
| `BI_pool`, `BI_diversity`, `BI_navigation` | со знаком: + означает больше ожидаемого |

Для cookie без курсора остатки MB и MIB пропущены (NaN), а не кодируются как большой остаток.

## 10. Смешанные факторы
- **Величины остатков MB, IB, MIB сильно зависят от длины cookie:** ρ с числом событий от −0.54 до −0.70, AUC «длинная против короткой» 0.16–0.22. Этим объясняется их кажущийся сигнал против упорных FP: после сопоставления по числу событий он исчезает.
- **Признаки BI от длины почти не зависят** (0.46–0.53).
- Признаки активности MB (`MB_activity`) почти целиком повторяют длину (ρ = 0.95).

## 19. Leakage audit (`research65/test_leakage65.py`: 7/7 **ok**)
1. Метки валидационного фолда перевёрнуты → остатки валидации идентичны (пул строится только по меткам обучения).
2. MB, IB, BI, MIB: строки валидации не участвуют ни в обучении отображения, ни в предобработке — мусорные данные валидации дают ту же модель.
3. Внутренние остатки строк обучения дня d считаются без дня d — мусорные данные дня d дают те же остатки.
4. В представлениях нет target, B0, вероятностей экспертов, UA и `cookie_id`.

Дополнительно:
- Все медианы, масштабы и IQR обучаются только на обучающих строках каждого fit.
- События только внутри окна (кэш циклов 3–6; проверено тестом цикла 6).
- Признаки и отображения не выбирались по валидации: ветка MB отсеяна правилом, заданным заранее (gate качества отображения на валидации P0 и fwd7, без меток).
- Test ни для какого выбора не использовался.

## 20. Итог исследования
Цикл 6.5 проверил последнюю принципиально новую гипотезу — условные межканальные остатки. Ответ отрицательный.
- **Mouse → behavior:** межканальной зависимости почти нет, курсор объясняет около 1% поведения. Поэтому вопрос «насколько поведение необычно для такого курсора» в этих данных бессодержателен.
- **Item ↔ behavior:** зависимость есть, но её остатки либо сводятся к длине cookie, либо отражают пул объявлений, который B0 уже использует, и направлены против нужного разделения.

Вместе с предыдущими циклами проверены:
- агрегатные признаки;
- граф и история объявлений;
- отпечатки сервисов;
- многообразие ботов;
- поздний фьюжн по каналам;
- локальное переранжирование;
- self-supervised предсказуемость последовательностей;
- динамика префиксов;
- условные межканальные остатки.

Ни одно направление не нашло независимого сигнала, который отделял бы 45 упорных FP от настоящих ботов или устойчиво поднимал P@R.

**B0 IS FINAL:**
- CatBoost, топ-120 признаков плюс пул item, 5 seed;
- repeated CV 0.9003, fwd7 0.9023, скрытый test 0.8953;
- `python solution/train_final_v2.py` воспроизводит `submission.csv` бит-в-бит.
