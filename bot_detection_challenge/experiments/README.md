# Эксперименты

Здесь всё исследование, из которого получилось итоговое решение `../solution.py`. Для запуска решения эта папка **не нужна**.

## Структура

| папка | цикл | что внутри | отчёт |
|---|---|---|---|
| `work/` | 1 | EDA, первые эксперименты, отбор признаков, ablation, сравнение моделей | `reports/REPORT.md`, `reports/README_SOLUTION.md` |
| `cycle1/` | 1 | модульный пайплайн: `features.py` (около 300 признаков-кандидатов), `history.py`, `cv.py`, `metrics.py` с тестами метрики, `train_final.py` (бленд цикла 1), `train_final_v2.py` (B0 до сборки в один файл), `submission_v1_cycle1.csv` | те же |
| `research2/` | 2 | строгая валидация `rcv.py` (повторные разбивки дней, fwd7, paired bootstrap), тесты утечек `test_leakage.py`, 17 гипотез; OOF итоговой модели — `oof_final_B0.csv` | `reports/REPORT_CYCLE2_SUMMARY.md`, `research2/REPORT_CYCLE2.md` |
| `research3/` | 3 | разбор 45 упорных ложных срабатываний, подтипы ботов, поиск «сервисов» | `reports/REPORT_CYCLE3_SUMMARY.md`, `reports/REPORT_CYCLE3.md` |
| `research4/` | 4 | отдельные детекторы mouse / behavior / item + слияние решений (Iliou et al., 2021) | `reports/REPORT_CYCLE4.md` |
| `research5/` | 5 | локальное переранжирование около рабочей точки | `reports/REPORT_CYCLE5.md` |
| `research6/` | 6 | self-supervised задачи, траектории на префиксах | `reports/REPORT_CYCLE6.md` |
| `research65/` | 6.5 | условные межканальные остатки | `reports/REPORT_CYCLE65.md` |
| `research7/` | 7 | методы победителей ISIT 2024: окна событий, кинематика курсора, LSTM / BiLSTM | `reports/REPORT_CYCLE7.md` |

- В каждой `researchN/` есть `RESEARCH_LOG.md` — хронологический журнал всех экспериментов, включая неудачные.
- Большие промежуточные файлы (OOF, кэши, parquet) в git не хранятся. Скрипты пересоздают их при запуске.

**Как запускать.** Для итогового решения эта папка не нужна. Если требуется воспроизвести исследование, сначала установите дополнительные зависимости из корня решения:

```bash
python3 -m pip install -r requirements-experiments.txt
```

Старые скрипты запускаются из этой папки, например `python3 cycle1/train_final_v2.py` или `python3 research2/test_leakage.py`. Результат пишется в `experiments/`, итоговый `../submission.csv` они не изменяют.

**Отличия от путей в отчётах.** После реорганизации:
- `solution/` переименована в `cycle1/`;
- `data` здесь — ссылка на `../data`;
- в отчётах циклов остались старые пути (`solution/...`, `research2/...`) — они относятся к этой папке.

## Правила, которые соблюдались во всех циклах
- Метки не менялись.
- `cookie_id` не использовался как признак и нигде не захардкожен.
- Нет ручной разметки и ручного разбора test.
- Нет внешних API и LLM.
- Решения принимались только по валидации, результат на test для выбора не использовался.
- Признаки, зависящие от меток, строились только по обучающей части фолда и только по более ранним дням.

## Сводка: что пробовали и что не улучшило итоговую модель

Итоговая модель (B0): **0.9003 ± 0.0035** на 5 разбивках дней, **0.9023** на fwd7, **0.8953** на скрытом test. Все кандидаты проверены на тех же разбивках, OOF строгий.

**Главный вывод исследования.** 45 из 59 ложных срабатываний у рабочей точки — cookie с меткой «человек», у которых курсор и выбор объявлений порождены теми же механизмами, что у ботов. По полям `events.csv` их не отличить: ни один подход не дал AUC выше 0.65 против похожих настоящих ботов. Выше 0.90 можно выйти только с новыми данными: сетевые атрибуты, серверная телеметрия, сенсоры на mobile.
